Политика конфиденциальности

Плёнка — личный фотодневник. Приложение не передаёт ваши записи разработчику и не продаёт и не показывает их никому.

Какие данные обрабатываются

  • Записи: фотографии, текст, теги, дата и время.
  • Место: координаты из GPS телефона или из данных снимка (EXIF) и название места. Геолокация запрашивается только пока приложение открыто.
  • Камера: используется только для съёмки фото в запись.

Где хранятся данные

  • На телефоне — во внутренней папке приложения. Другие приложения и галерея их не видят.
  • В вашем Google Drive — если вы подключили синхронизацию. Копии записей сохраняются в папку «Плёнка» в вашем собственном аккаунте.

Доступ к Google Drive

Приложение запрашивает только доступ https://www.googleapis.com/auth/drive.file. Это файлы, которые создало само приложение. Остальные файлы на вашем Drive приложению недоступны. Данные из Google API используются только для резервной копии и восстановления дневника и никому не передаются.

Use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Кнопка «Поделиться»

Фото уходит в другое приложение только когда вы сами нажимаете «Поделиться» или проводите вверх в полноэкранном просмотре. Приложение передаёт копию одного фото в формате JPEG тому приложению, которое вы выбрали в системном меню. Текст, теги и место записи не передаются.

Сторонние сервисы

  • Карта записей: подложка карты загружается с серверов OpenStreetMap (tile.openstreetmap.org), библиотека карт — с unpkg.com. Эти сервисы видят ваш IP-адрес и показываемый участок карты, но не тексты и фото записей.
  • Название места: чтобы превратить координаты в адрес, используется системный геокодер Android, который отправляет координаты поставщику геосервисов телефона.
  • Обновления приложения: при запуске приложение спрашивает у сервера обновлений Expo (u.expo.dev), нет ли новой версии, и скачивает её. Сервер видит IP-адрес, версию приложения и модель телефона, но не записи.
  • Аналитики, рекламы и трекеров в приложении нет.

Удаление данных

Запись удаляется в самом приложении. Все данные на телефоне удаляются вместе с приложением. Копию в Google Drive можно удалить, удалив папку «Плёнка», а доступ приложения отозвать на странице myaccount.google.com/permissions.

Summary in English

Plenka is a personal offline photo diary for Android. Posts (photos, text, tags, date, location) are stored on the device and, if the user connects it, backed up to the user's own Google Drive using only the drive.file scope. No data is sent to the developer or sold or shared with third parties. A single photo is handed to another app only when the user taps Share (sent as a JPEG copy, without the post text, tags or location). There are no ads, analytics or trackers. On launch the app asks the Expo update server (u.expo.dev) for a newer version of its code. The map screen loads tiles from OpenStreetMap (tile.openstreetmap.org) and the map library from unpkg.com. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data can be deleted in the app, by uninstalling it, by deleting the "Плёнка" folder in Google Drive, and access can be revoked at myaccount.google.com/permissions.
